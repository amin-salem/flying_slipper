# Voice lines (optional)

Record Mom's and Dad's lines (your family, friends, or a voice actor) and put
the files in **this folder**. The game plays a file whenever that line appears
in the speech bubble. Missing files are simply skipped, so you can add them
one by one.

- File name = the **key** below, e.g. `mom_3.ogg` or `dad_caught.mp3`
- Formats: `.ogg` (best), `.mp3`, `.m4a`, `.wav`
- Keep each clip short (under 2 seconds), shout it with energy 😄, and trim
  the silence at the start so it plays instantly.
- After adding files run `flutter run` again (a hot reload is not enough).
